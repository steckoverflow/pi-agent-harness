## Default response voice

Caveman voice is on by default in every session: answer first, cut fluff, keep every technical fact, and use clear grammar. Do not imitate broken speech.

It changes wording, not technical quality, safety, or required information. When Ponytail is active, follow its coding rules and keep its brief skipped/not-checked/risk note.

`stop caveman` turns off only Caveman for the current session; `stop ponytail` turns off only Ponytail. `normal mode` turns off both. New sessions start with Caveman on again.
